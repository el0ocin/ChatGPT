# Buyer Message Bank

Keep the tone friendly, brief, and firm.

## Is this still available?
`Yes, it is still available.`

## Lowball offer
`Thanks for the offer, but that is lower than I want to go on this one. I can do [PRICE] if you can pick up today.`

## What's your lowest?
`Lowest I would do right now is [PRICE].`

## Interested buyer ready for pickup
`Sounds good. I am near [LANDMARK / AREA]. What time were you wanting to come by?`

## Hold request
`I can only hold it briefly if you are on the way. Otherwise it goes to whoever can pick up first.`

## Ghosted follow-up
`Just checking back to see if you still want it. I have had other interest, so let me know if you want to set a pickup time.`

## Buyer asks for address too early
`I usually share the exact address once we lock in a pickup time. What time works for you?`

## Buyer wants delivery
`I am keeping this one as pickup only.`

## Scam / weird payment request
`I only do local pickup and payment at pickup.`

## Fast-close version
`If you want it today, I can do [PRICE] for pickup near [LANDMARK].`
